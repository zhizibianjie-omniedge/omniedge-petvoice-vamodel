## 📊 PetVoice VA 数据集概览 | PetVoice VA Dataset Overview

### 🎯 数据集基本信息
**PetVoice VA Dataset** 是目前**全球最大规模**的宠物发声效价-唤醒度标注数据集，专为宠物情感识别研究而构建。

| 属性 | 详情 | 说明 |
|------|------|------|
| **数据集名称** | PetVoice VA Dataset | 宠物发声效价-唤醒度数据集 |
| **样本规模** | **42,553+** | 持续增长中 |
| **标注类型** | VA连续空间标注 | 效价 + 唤醒度 |
| **标注质量** | **95%+ 一致性** | 多重验证机制 |
| **更新频率** | 每月2,000+ | 持续更新 |
| **格式支持** | WAV, JSON, CSV | 多种数据格式 |

### 🏷️ 标注详情 | Annotation Details

#### 🎭 VA情感空间标注
每个样本都包含精确的VA坐标标注：
- **效价 (Valence)**: [-1, 1] 范围，表示情感的积极/消极程度
- **唤醒度 (Arousal)**: [-1, 1] 范围，表示情感的激活/平静程度
- **置信度**: [0, 1] 范围，表示标注的可靠性
- **标注时间**: 精确到毫秒的时间戳
