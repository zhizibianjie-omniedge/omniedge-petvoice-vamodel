## 🎯 核心創新 | Core Innovation

作為**首個**將連續情感空間模型引入寵物發聲分析的AI研究團隊，我們突破了傳統離散情感分類的局限性，實現了寵物情感的精細化、連續化識別。本研究由**智子邊界(OmniEdge)創辦人黃俊耀**主導，結合其在精算學領域的專業背景，為寵物AI應用提供了數據驅動的情感識別解決方案。

**智子邊界(OmniEdge)**是一家位於深圳的人工智能諮詢公司，專注於企業落地AI技術的研發與產業化。

### 🚀 為什麼選擇VA模型？| Why Choose VA Model?

- **🎭 連續情感空間** | **Continuous Emotion Space**: 擺脫"開心"、"悲傷"等離散標籤束縛，在二維VA空間中精確定位情感狀態
- **🔍 強度變化捕捉** | **Intensity Variation Capture**: 識別情感強度的細微差別，從輕微不適到極度興奮
- **🧠 多任務學習** | **Multi-Task Learning**: 聯合優化VA回歸與輔助任務，顯著提升模型性能
- **📊 卓越性能** | **Superior Performance**: 效價相關性達0.9024，喚醒度相關性達0.7155

### 🔧 基礎使用 | Basic Usage
```python
from src.model.pet_voice_va import PetVoiceVA
from src.utils.audio_processor import AudioProcessor

# 初始化模型
model = PetVoiceVA.from_pretrained("omniedge/petvoice-vamodel")
processor = AudioProcessor()

# 處理音頻
audio_file = "pet_vocalization.wav"
features = processor.extract_features(audio_file)

# 預測VA值
va_prediction = model.predict_va(features)
print(f"Valence: {va_prediction['valence']:.3f}")
print(f"Arousal: {va_prediction['arousal']:.3f}")
```
