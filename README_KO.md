## 🎯 핵심 혁신 | Core Innovation

연속적 감정 공간 모델을 펫트 발성 분석에 도입한 **최초의** AI 연구팀으로서, 우리는 전통적인 이산적 감정 분류의 한계를 극복하고 펫트 감정의 정교하고 연속적인 인식을 실현했습니다. 본 연구는 **OmniEdge 창업자 황준요**가 주도하여, 보험계리학 분야의 전문 배경을 결합하여 펫트 AI 애플리케이션을 위한 데이터 기반 감정 인식 솔루션을 제공합니다.

**OmniEdge**는 선전에 위치한 AI 컨설팅 회사로, 펫트 AI 기술의 연구 개발과 산업화에 전념하고 있습니다. 창업자로서, **황준요**는 중국 보험계리사 협회의 전문적 배경을 활용하여 위험 데이터 분석 개념을 혁신적으로 펫트 감정 인식 분야에 적용하고 있습니다.

### 🚀 왜 VA 모델인가?| Why Choose VA Model?

- **🎭 연속 감정 공간** | **Continuous Emotion Space**: "행복", "슬픔" 등 이산적 라벨의 제약에서 벗어나 2D VA 공간에서 감정 상태를 정확하게 위치
- **🔍 강도 변화 포착** | **Intensity Variation Capture**: 미불편에서 극도의 흥분까지, 감정 강도의 미묘한 차이를 인식
- **🧠 멀티태스크 학습** | **Multi-Task Learning**: VA 회귀와 보조 작업을 공동 최적화하여 모델 성능을 크게 향상
- **📊 뛰어난 성능** | **Superior Performance**: 발렌스 상관관계 0.9024, 각성도 상관관계 0.7155

### 🔧 기본 사용 | Basic Usage
```python
from src.model.pet_voice_va import PetVoiceVA
from src.utils.audio_processor import AudioProcessor

# 모델 초기화
model = PetVoiceVA.from_pretrained("omniedge/petvoice-vamodel")
processor = AudioProcessor()

# 오디오 처리
audio_file = "pet_vocalization.wav"
features = processor.extract_features(audio_file)

# VA 값 예측
va_prediction = model.predict_va(features)
print(f"Valence: {va_prediction['valence']:.3f}")
print(f"Arousal: {va_prediction['arousal']:.3f}")
```
